# Примеры: слабо → сильно

Факты условные, это иллюстрация механики. В реальной работе факты берём только у заказчика.

## 1. Рассылка: личная причина

Слабо:

```
Друзья! Уникальное предложение для вас! Запишитесь на пробное занятие в нашей студии и откройте для себя мир танца! Количество мест ограничено!
```

Что не так: «друзья», «уникальное», «откройте для себя», ограничение без числа, нет причины писать именно этому человеку, нет конкретики.

Сильно:

```
{имя}, вы смотрели наше видео про первое занятие 💡

Пишу лично, потому что вы досмотрели до конца, а таких немного.

Пробное занятие длится 45 минут. Приходите в удобной одежде, остальное возьмём на себя. В группе начинающих в этот вторник свободно 4 места из 12.

👇 Напишите в ответном сообщении «Хочу во вторник», и я запишу вас

[НУЖНО: подтвердить дату и число мест]
```

Почему работает: есть причина написать (человек досмотрел видео), есть конкретика (45 минут, 4 места из 12), одно действие от первого лица.

## 2. Рассылка: кейс

Слабо:

```
Наши клиенты добиваются потрясающих результатов! Присоединяйтесь!
```

Сильно:

```
{имя}, Ольге 54 года, она бухгалтер и до января не вставала на лыжи

Сегодня Ольга проходит 10 километров за два часа. Начинала с 800 метров, занятия по субботам.

Расскажу, с чего она начала и что поменяла в первый месяц. Ничего сложного: три тренировки в неделю по 40 минут и один простой план на каждый день.

👇 Напишите «Хочу так же», и я пришлю её первый план
```

Почему работает: есть имя, возраст, исходная точка, цифра и срок. Один смысл: пример конкретного человека.

## 3. Пост: без продажи, с выводом

Слабо:

```
Друзья, сегодня поговорим о порядке в шкафу. Порядок это не просто красота, а основа комфорта. Подписывайтесь, чтобы не пропустить новое!
```

Сильно:

```
Как за 10 минут понять, какие вещи в шкафу можно отдать

Достаньте всё с одной полки и разложите на три стопки: ношу каждую неделю, ношу редко, не надевал год.

Третью стопку уберите в пакет и закройте. Через месяц загляните: что не понадобилось, то можно отдать.

Попробуйте на одной полке сегодня и напишите в комментариях, сколько вещей оказалось в третьей стопке.
```

Почему работает: один смысл, конкретный шаг на сегодня, нет имени и нет «подписывайтесь», в конце действие.
