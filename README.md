# Русский копирайтер для рассылок и постов

Меня зовут Дима. Я креативный директор по маркетингу в компании, более 8 лет создаю автоворонки, пишу тексты и создал более 150 автоматических воронок продаж.

Скилл основан на сотнях рассылок и автоворонках, подтверждённых цифрами и результативностью.

Это мой первый скилл, буду рад обратной связи.

Скилл пишет короткие тексты на русском: рассылки и посты. Сначала задаёт бриф, потом пишет по принципу «один текст, одна мысль, одно действие». Перед сдачей проходит корректором: орфография, падежи, числительные. Не выдумывает факты и не использует штампы вроде «друзья!» и «не просто X, а Y».

*English: a skill for writing short Russian marketing texts (broadcast messages and channel posts). It starts with a brief, writes one idea and one action per text, and proofreads before delivering. Built from patterns in hundreds of real measured mailings.*

## Пример

Слабо:

```
Друзья! Уникальное предложение для вас! Запишитесь на пробное занятие в нашей студии и откройте для себя мир танца!
```

Сильно:

```
{имя}, вы смотрели наше видео про первое занятие 💡

Пишу лично, потому что вы досмотрели до конца, а таких немного.

Пробное занятие длится 45 минут. Приходите в удобной одежде, остальное возьмём на себя.

👇 Напишите в ответном сообщении «Хочу во вторник», и я запишу вас
```

## Как поставить

Скопируйте папку `skills/copywriter-a` туда, где ваш агент ищет скиллы. Для Claude Code это `~/.claude/skills/`.

Лучше всего работает на сильных моделях с режимом рассуждений: Claude Opus или Sonnet, флагманский GPT с Thinking.
